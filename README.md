## Overview

FiveM is the most widely used multiplayer modification platform for Grand Theft Auto V, enabling players to connect to thousands of custom multiplayer servers running unique game modes — roleplay, racing, deathmatch, and more — without affecting the original Rockstar Online installation. Built on the Citizen framework, it provides server operators a complete scripting API in Lua, C#, and JavaScript for building custom experiences.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **FiveM** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Custom Server Network** | Thousands of community servers with unique game modes and communities |
| **Citizen Framework** | Full server scripting API in Lua, JavaScript, and C# for developers |
| **Original Game Untouched** | Runs completely separately from GTA Online and story mode |
| **Anti-Cheat** | Built-in ban enforcement system protecting communities from cheaters |
